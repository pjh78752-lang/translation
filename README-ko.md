# 애니매니악스 메가드라이브 한국어 패치 0.1

첨부된 미국판 ROM에 맞춰 제작한 IPS 패치입니다. 원본 ROM은 패치 묶음에 포함하지 않습니다.

## 적용 방법

1. ZIP을 풀고, 아래 SHA-256과 일치하는 원본 ROM을 준비합니다.
2. IPS 패치 도구로 `Animaniacs-Korean.ips`를 원본에 적용합니다.
3. 생성된 ROM을 메가드라이브/제네시스 에뮬레이터에서 새로 실행합니다.

Python 3이 있다면 패치 파일과 `apply_patch.py`를 같은 폴더에 두고 다음과 같이 적용할 수도 있습니다.

```sh
python apply_patch.py "Animaniacs (USA).md" "Animaniacs-Korean.md"
```

원본 파일을 덮어쓰지 마세요. 기존 세이브스테이트 대신 처음부터 실행하세요.

- 원본 크기: 1,048,576바이트, 헤더 없는 메가드라이브 ROM
- 원본 SHA-256: `31fbf9d442d578c43788a024336639648d5c7dab4502636e127190c991ff3604`
- 패치 후 크기: 2,097,152바이트

## 번역 범위

- 스토리 대사 85개 전체
- 시작·암호·설정 메뉴, 난이도·음향·조작 기능 이름
- 스테이지 이름 5개와 작중 영화 제목
- 암호 입력 오류 안내
- 16×16 한글 글꼴 및 대사 출력 확장, 줄바꿈·스크롤 정렬

게임 로고와 그림 안의 영문, 제작진 크레딧, 일부 숫자·버튼 표시는 원래대로 남아 있습니다. 음성은 변경하지 않았습니다. 원문의 패러디 이름과 말장난은 한국어 문맥에 맞게 옮겼습니다.

## 검증과 한계

Genesis Plus GX에서 부팅, 한국어 메뉴 표시, 첫 스테이지 진입과 조작을 확인했습니다. 대사 85개는 에뮬레이터의 도입부 상태에서 각각 불러와 글자 출력 1,923회와 종료 처리를 확인했습니다. 이는 게임을 처음부터 끝까지 직접 플레이한 검증과는 다릅니다. 실기와 다른 에뮬레이터에서는 검증하지 않았습니다.

`build-info.json`에는 원본·결과 해시와 ROM 체크섬이, `validation.json`에는 대사별 검증 결과가 있습니다. 패치는 초기 버전입니다.

## 글꼴

Noto Sans CJK Bold를 비트맵으로 변환하여 사용했습니다. 원 저작권과 SIL Open Font License는 `FONT-LICENSE.txt`를 참조하세요.

## 수정용 자료

`source/dialogue-ko.json`은 대사 번역이며, `source/tools`에는 빌드·글꼴 출력 코드가 있습니다. 빌드에는 Pillow, GNU m68k binutils, Noto Sans CJK 글꼴이 필요합니다. 제공 빌드 스크립트의 도구 경로는 제작 환경 기준이므로 다른 컴퓨터에서는 조정해야 합니다.
